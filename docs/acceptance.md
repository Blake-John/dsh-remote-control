# 真机验收记录（v2.0.0）

本文件记录 dsh-remote-control 在真实设备上的一次完整验收。**验收通过**是 2.0.0 冻结的依据。

- **日期**：2026-10-23
- **版本**：2.0.0（验收时为 1.9.0 的代码，验收后仅版本号前进）
- **环境**：`dsh web`（web profile，默认回环绑定，零参数启动）；入口监听器绑定本机一个 Tailscale 地址的 `3080` 端口；明文 HTTP，链路由 tailnet 加密；`allowFrom` 未设置（仅密码）
- **客户端**：Windows · Chrome（经 tailnet 访问）
- **服务端**：Linux 主机，插件以 profile bundle 方式安装（`link:` 到本仓库）

## 本次验收覆盖不到的

| 项 | 说明 |
|---|---|
| TLS | 入口为明文 HTTP；未在公网或不可信网络验证（也不建议） |
| 多地址 | 仅单地址绑定；局域网 IP 与 tailnet IP 同时可用未验证 |
| 邀请码 | 逻辑与端到端测试覆盖，但本次真机未走邀请码路径 |
| 上游改版 | 代理依赖的公开面（`authenticatedUrl` / `admit` / 头改写假设）没有跨版本回归测试 |

## 冻结说明

2.0.0 表示**功能面稳定**，不是"不再改动"。以下情况才值得动它：

1. 真机使用中发现具体缺陷；
2. 上游公开 API 变更导致挂载或代理失效；
3. 明确的新需求（例如入口地址二维码、TLS 字段、多地址监听）。

自动化测试（54 条）是回归基线：`node --test tests/*.test.mjs`。
